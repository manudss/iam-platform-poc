Enable Real execution?

Runs of this workflow can call Jira Support and create real issues outside lyam.

External effects are not isolated in a Dolt branch and cannot be undone by discarding it.
Before enabling

Check the connection, project and request fields. A saved Real setting applies to future scheduled and manual runs. Editor tests still simulate external calls.

If a creation response is uncertain, the run stops for review. Retry and error-route continuation are blocked to avoid duplicates.
