No host execution has been authorized by this document. Keep the GitHub entry's existing guards. scripts/normal-runtime-host-fixture.py is a distinct entry requiring root, a new private hash-bound spec, explicit --execute-reviewed-host-fixture, and protected code ancestry. Its default invocation only checks prerequisites. A spec is not consent.

The spec fields are format=1, kind=reviewed-host-pre-fifo-fixture, exact existing image81aeb and source276d32, files mapping all three fixed host-entry/shared-engine/normal-controller relative paths to reviewed hashes, and out=/root/normal-host-proof-<16lowerhex>.json. No production stores, env, credentials, paths or companions are read or mounted. Only fixture /root/normal-fixture-.../data empty and synthetic seednever env are used. Bounded artifact reports fixed controller errors/count/family and no raw command/stdout/stderr/env. Root output path must not preexist. A success qualifies only the pre-FIFO network mechanism on this host/kernel/Docker. It does not authorize adoption, release, boot, updater, real stores, upstream effects or CI.

This new host mode has only local tests/doubles, not real execution. Shared-engine GitHub mode needs a fresh regression run after refactor.
