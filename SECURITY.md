# Security policy

## Scope

This is a proprietary demonstration proof of concept (see LICENSE). It is not
designed, tested or hardened for production use: the hosted demo uses fictional
users, fictional data and intentionally non-secret demo passwords. Do not deploy it
to protect real identities or data.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Security Advisories**
("Report a vulnerability" button on the repository's Security tab), not in a public
issue. If private reporting is not enabled, open an issue without details and ask
for a private channel.

Please include: affected endpoint/component, reproduction steps, and impact. There
is no support commitment and no bounty program.
